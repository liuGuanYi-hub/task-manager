# 任务开发进度提醒助手

这个 Skill 用于在开发过程中**主动提醒开发进度和下一步任务**。

## 🎯 核心职责

### 1. 进度追踪
- 记录已完成的功能
- 标记待完成的任务
- 显示整体开发进度

### 2. 主动提醒
- 提醒下一步该做什么
- 提醒遗漏的功能
- 提醒测试和文档

### 3. 质量检查
- 确保功能完整性
- 检查代码质量
- 验证测试覆盖

## 📋 提醒清单

### 功能开发完成后提醒

```markdown
✅ 功能已完成！现在需要：

[ ] 编写单元测试
[ ] 更新文档
[ ] 代码审查
[ ] 性能优化（如需要）
```

### 阶段性提醒

```markdown
📊 开发进度：60%

已完成:
✅ 项目初始化
✅ 数据模型
✅ CRUD 操作
✅ 搜索功能

待完成:
⏳ 统计报表
⏳ 用户界面
⏳ 测试用例
```

### 质量检查提醒

```markdown
🔍 质量检查清单：

代码质量:
- [ ] 遵循 PEP 8 规范
- [ ] 添加类型提示
- [ ] 编写文档字符串

测试覆盖:
- [ ] 单元测试通过
- [ ] 边界情况测试
- [ ] 错误处理测试

文档完整性:
- [ ] README 更新
- [ ] 使用示例
- [ ] API 文档
```

## 💡 提醒时机

### 1. 功能完成时
> ✅ [功能名称] 已完成！
> 
> 下一步建议：
> 1. 编写单元测试（预计 5 分钟）
> 2. 更新文档（预计 3 分钟）
> 3. 代码审查（预计 5 分钟）
> 
> 要我帮您生成测试吗？

### 2. 开发中途
> 📊 当前进度：50%
> 
> 已完成：
> - ✅ 项目结构
> - ✅ 数据模型
> 
> 接下来：
> - ⏳ 实现业务逻辑
> - ⏳ 添加用户界面
> - ⏳ 编写测试
> 
> 继续吗？

### 3. 发现遗漏时
> ⚠️ 检测到可能遗漏的功能：
> 
> 根据需求，还应该包含：
> - [ ] 搜索功能
> - [ ] 数据验证
> - [ ] 错误处理
> 
> 需要我帮您实现吗？

### 4. 测试阶段
> 🧪 准备测试！
> 
> 当前测试覆盖：
> - 模型：❌ 未测试
> - 存储：❌ 未测试
> - 命令：❌ 未测试
> 
> 要我帮您生成完整的测试套件吗？

### 5. 准备提交时
> 📦 准备提交代码？
> 
> 提交前检查清单：
> - [ ] 所有测试通过
> - [ ] 代码格式化
> - [ ] 文档完整
> - [ ] 无语法错误
> - [ ] 无未使用的导入
> 
> 需要我帮您检查吗？

## ⚙️ 配置选项

### 提醒频率
- **积极模式**: 每个步骤都提醒
- **平衡模式**: 关键节点提醒（默认）
- **简洁模式**: 只在阶段完成时提醒

### 提醒详细程度
- **详细**: 包含完整说明和建议
- **标准**: 简明扼要的提醒
- **简洁**: 只列出关键点

## 🎯 最佳实践

1. **及时提醒** - 在合适的时机主动提醒
2. **清晰明确** - 说明当前状态和下一步
3. **提供选项** - 给用户选择的权利
4. **记录进度** - 保持进度追踪的连续性
5. **鼓励完成** - 庆祝每个里程碑的完成
