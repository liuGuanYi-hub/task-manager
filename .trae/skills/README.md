# AI Skill 使用指南

## 什么是 AI Skill？

AI Skill 是 Trae IDE 中的**自定义 AI 助手配置**，用于：
- 指导 AI 在特定场景下如何行为
- 定义 AI 的触发条件
- 规范 AI 的生成内容
- 提供主动提醒机制

## 已创建的 Skill

**作用**: 在 Python 开发过程中主动提醒并提供代码生成服务

## 如何使用 Skill

### 方法 1: 主动触发

当您看到 AI 的提醒时，直接回复确认即可：

```
AI: 💡 我可以使用 dev-accelerator Skill 帮您快速生成这个项目...

您：好的，开始吧！
```

### 方法 2: 手动调用

在对话中明确提到 Skill 名称：

```
您：请使用 dev-accelerator Skill 帮我生成项目结构
```

### 方法 3: 自动触发

AI 会根据您的开发阶段自动识别并提醒：

```
您：我要创建一个任务管理系统

AI: （识别到项目初始化阶段，自动提醒使用 dev-accelerator）
```

## Skill 文件结构

每个 Skill 包含：

```
.trae/skills/
└── <skill-name>/
    └── SKILL.md
```

### SKILL.md 格式

```markdown
---
name: "skill 名称"
description: "简短描述（包含功能和触发时机）"
---

# Skill 标题

详细说明...

## 触发场景
- 场景 1
- 场景 2

## 功能列表
- 功能 1
- 功能 2

## 使用示例
示例代码...
```

## 最佳实践

### ✅ 推荐做法

1. **明确的触发条件**
   - 在 description 中清楚说明何时触发
   - 列举具体的使用场景

2. **清晰的提醒格式**
   - 使用 emoji 增加可读性
   - 提供进度条和清单
   - 给出时间估算

3. **尊重用户选择**
   - 提醒后等待用户确认
   - 不要过度打扰
   - 允许用户跳过

4. **提供具体价值**
   - 说明能节省多少时间
   - 列出具体的产出物
   - 展示完成后的效果

### ❌ 避免做法

1. **过度提醒** - 每个步骤都提醒会打扰用户
2. **模糊描述** - 不明确说明能做什么
3. **强制执行** - 不等待用户确认就行动
4. **重复提醒** - 用户拒绝后不再提醒

## Skill 之间的协作

多个 Skill 可以协同工作：

```
开始项目
    ↓
dev-accelerator 提醒并生成项目骨架
    ↓
开发功能
    ↓
task-reminder 追踪进度并提醒下一步
    ↓
需要代码生成
    ↓
python-dev-helper 提供代码协助
    ↓
功能完成
    ↓
task-reminder 提醒编写测试
    ↓
dev-accelerator 生成测试用例
    ↓
完成！
```

## 调试技巧

### 检查 Skill 是否生效

1. 查看 `.trae/skills/` 目录是否存在
2. 确认 SKILL.md 格式正确
3. 检查 frontmatter 是否完整
4. 在对话中尝试触发

### 常见问题

**Q: Skill 没有触发？**
- 检查 description 是否包含触发条件
- 确保关键词匹配
- 尝试手动提到 Skill 名称

**Q: 提醒太频繁？**
- 调整提醒频率配置
- 使用简洁模式
- 明确告诉 AI 减少提醒

**Q: 提醒不够及时？**
- 在 description 中添加更多触发场景
- 使用积极模式
- 明确告诉 AI 需要更多提醒
