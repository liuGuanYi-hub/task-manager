## 💡 核心功能

### 主动提醒机制
1. **识别开发阶段** - 根据用户行为判断当前开发阶段
2. **适时提醒** - 在关键节点主动提醒用户可以使用 Skill
3. **提供选项** - 给出具体的加速方案供用户选择

### 代码生成能力
1. **项目骨架** - 完整的项目结构
2. **功能模块** - 符合最佳实践的代码
3. **测试用例** - 全面的单元测试
4. **配置文件** - 依赖和配置管理
5. **文档** - 清晰的使用说明

### 开发指导
1. **最佳实践** - 遵循 Python 编码规范
2. **架构建议** - 合理的项目组织
3. **性能优化** - 高效的代码实现
4. **错误处理** - 健壮的异常处理

## ⚠️ 注意事项

1. **不要过度提醒** - 每个开发阶段提醒 1-2 次即可
2. **尊重用户选择** - 用户拒绝后不要重复提醒
3. **提供价值** - 确保提醒时明确说明能带来的好处
4. **时机恰当** - 在用户可能需要帮助时提醒，不要打断思路
