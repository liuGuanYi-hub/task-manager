# Python 开发助手

这个 skill 帮助加速 Python 项目开发过程。

## 功能

1. **快速生成代码结构** - 根据需求生成符合项目风格的代码
2. **单元测试编写** - 为现有代码生成 pytest 测试用例
3. **Bug 快速定位** - 分析错误信息，提供解决方案
4. **代码优化建议** - 提供性能优化和最佳实践建议
5. **功能扩展** - 根据现有架构添加新功能

## 使用场景

- 需要创建新功能模块时
- 需要为现有代码编写测试时
- 遇到 bug 需要快速解决时
- 需要重构或优化代码时
- 需要添加 Web 界面、API 等扩展功能时

## 开发原则

1. 保持代码简洁、可读性强
2. 遵循项目现有代码风格
3. 优先使用项目已有的依赖库
4. 提供完整的类型提示
5. 编写清晰的文档字符串
