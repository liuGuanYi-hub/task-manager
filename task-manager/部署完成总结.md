## 🚀 部署方式

### 方式一：自动部署（推荐）

```powershell
# 在项目目录执行
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\deploy.ps1
```

**脚本会自动完成**:
1. ✅ 检查 Git 安装
2. ✅ 初始化 Git 仓库
3. ✅ 添加所有文件
4. ✅ 提交代码
5. ✅ 设置主分支
6. ✅ 关联远程仓库
7. ✅ 推送到 GitHub

### 方式二：手动命令


## 🔑 认证设置

### 使用 Personal Access Token（推荐）

**步骤**:
1. 访问 https://github.com/settings/tokens
2. 创建新 token（勾选 `repo` 权限）
3. 复制 token
4. 推送时使用 token 代替密码

```bash
git push https://<username>:<token>@github.com/liuGuanYi-hub/task-manager.git
```

### 使用 SSH 密钥

**步骤**:
1. 生成密钥：`ssh-keygen -t ed25519 -C "your_email@example.com"`
2. 添加公钥到 GitHub：https://github.com/settings/keys
3. 切换远程地址：
   ```bash
   git remote set-url origin git@github.com:liuGuanYi-hub/task-manager.git
   ```
