# 🚀 立即部署指南

## ⚡ 快速三步部署

### 第 1 步：安装 Git（2 分钟）

**浏览器应该已经打开** https://git-scm.com/download/win

1. 点击下载 **Git for Windows**
2. 运行下载的安装程序
3. 一直点击 "Next"
4. 选择 **"Git from the command line"**（重要！）
5. 完成安装

---

### 第 2 步：重启 PowerShell

安装完成后：
1. **关闭当前 PowerShell 窗口**
2. **重新打开 PowerShell**
3. 验证 Git 安装：
   ```powershell
   git --version
   ```
   应该显示版本号，如：`git version 2.45.1.windows.1`

---

### 第 3 步：运行自动部署

```powershell
# 进入项目目录
cd C:\Users\Administrator\Desktop\zzd\task-manager

# 运行自动部署脚本
.\auto-install-and-deploy.ps1
```

脚本会自动帮您：
- ✅ 配置 Git 用户信息
- ✅ 初始化 Git 仓库
- ✅ 添加所有文件
- ✅ 提交代码
- ✅ 设置主分支
- ✅ 关联远程仓库
- ✅ 推送到 GitHub

## 🔑 创建 Personal Access Token

### 方法 1: 自动打开

运行以下命令会自动打开创建页面：
```powershell
Start-Process "https://github.com/settings/tokens"
```

### 方法 2: 手动访问

1. 访问：https://github.com/settings/tokens
2. 点击 **"Generate new token (classic)"**
3. 填写备注：`task-manager-deploy`
4. 勾选权限：✅ **repo** (Full control of private repositories)
5. 点击 **"Generate token"**
6. **复制并保存 Token**（只显示一次！）

## 🆘 遇到问题？

### 问题 1: PowerShell 提示权限不足

**解决**:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 问题 2: Git 命令找不到

**解决**: 
- 重启 PowerShell 窗口
- 确认安装时选择了 "Git from the command line"

### 问题 3: 推送时认证失败

**解决**:
- 使用 Personal Access Token，不是 GitHub 密码
- 重新生成 Token 并确认权限

### 问题 4: 远程仓库不存在

**解决**:
1. 访问：https://github.com/new
2. 创建仓库名：`task-manager`
3. **不要**初始化（不要勾选 README、.gitignore、license）
4. 点击 "Create repository"
5. 重新运行部署脚本
